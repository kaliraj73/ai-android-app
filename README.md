# ai-android-app
An Android application powered by a cloud-based AI backend built with FastAPI and deployed on Modal. This app provides intelligent text features including AI text generation, summarization, and sentiment analysis — all processed through a scalable serverless backend.

## Advanced AI Agent Tools
| Upgrade | What It Enables |
| --- | --- |
| Tool calling system | AI can use calculator, search, etc. |
| Multi-agent setup | One agent codes, one plans, one reviews |
| Memory ranking | AI remembers important facts only |
| Auto task execution | User says “Make a website” → AI builds plan |
